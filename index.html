Try it

Run it on your laptop.

No GPU and no Isaac. Four lines, then a MuJoCo window with the K1 following a sample motion, or an mp4 you can share.

GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 --filter=blob:none --sparse https://github.com/Kyk0/sonic-k1 && cd sonic-k1
git sparse-checkout set gear_sonic/scripts examples/k1 gear_sonic/data/assets/robot_description
pip install mujoco onnxruntime numpy "imageio[ffmpeg]" huggingface_hub
hf download Kyry10/sonic-k1 onnx/policy_g1.onnx k1_plant.json --local-dir checkpoints/sonic-k1

python gear_sonic/scripts/play_k1.py                      # live viewer (macOS: mjpython)
python gear_sonic/scripts/play_k1.py --record demo.mp4

Your own clip: retarget it to the K1 with UMR and pass --motion my_clip.npz. Share it with #SONICK1.
